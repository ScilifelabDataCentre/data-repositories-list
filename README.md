# data-repositories-list

This repository holds the list of data sources and data repositories. It is the single source of truth, and should be used by all SciLifeLab Data Centre Services aiming to provide information on data sources and data repositories 

## Services 

The following SciLifeLab Data Centre services are currently using this list:

- data.scilifelab.se
- SciLifeLab Open Science Monitor
- SciLifeLab Precision Medicine Portal
- SciLifeLab RDM guidelines
- Swedish Pathogens Portal
